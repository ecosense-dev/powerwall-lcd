# Waveshare A7670X (4G LTE) on the LCD-7

The firmware talks to a **SIMCom A7670** module (A7670X series: A7670E Europe, A7670G, etc.) on **UART1**, 115200 8N1, **no flow control**. `esp_modem` uses the **SIM7600** profile (compatible AT set). PPP starts only when an **APN** is configured.

HAT used: [Waveshare A7670E Cat-1 HAT](https://www.waveshare.com/wiki/A7670E_Cat-1/GNSS_HAT) (same pinout as the A7670X HAT family).

## Do not

- **Do not** wire modem TX/RX to the LCD-7 **RS485 A/B** terminals. Those pins go through an **SP3485** and are **differential RS-485**, not TTL UART.
- **Do not** power module `VBAT` from the ESP32-S3 3.3 V rail. TX peaks are on the order of **2 A**.
- **Do not** use the LCD-7 Type-C **USB** port for the modem: it defaults to CAN. Console and flash stay on Type-C **UART / UART1**.

## Firmware pins

Defined in `main/app_lte.h`:

| ESP32-S3 function | GPIO | On the LCD-7 | On the A7670X HAT |
|-------------------|------|--------------|-------------------|
| UART1 TX | **15** | MCU-side `RS485_TXD` (SP3485 DI) | **RXD** (or `RX`) |
| UART1 RX | **16** | MCU-side `RS485_RXD` (SP3485 RO) | **TXD** (or `TX`) |
| GND | — | GND | GND |
| PWRKEY (optional, **not** pulsed by firmware) | 6 | Sensor **AD** | PWRKEY |

UART must be crossed:

```
LCD-7 GPIO15 (TX)  ---->  A7670X RXD
LCD-7 GPIO16 (RX)  <----  A7670X TXD
LCD-7 GND          ----   A7670X GND
```

## Where to pick up GPIO15/16 on the LCD-7

GPIO 15 and 16 feed the SP3485, then the RS485 A/B connector. The modem needs the **MCU side, before the transceiver**.

Practical options:

1. **Pads / vias `RS485_TXD` and `RS485_RXD`** on the PCB (silkscreen or the [schematic](https://files.waveshare.net/wiki/ESP32-S3-Touch-LCD-7/ESP32-S3-Touch-LCD-7-Sch.pdf)): solder two wires plus GND.
2. **IO15 / IO16** of the ESP32-S3 if you can reach test points.
3. Do **not** use the board HY2.0 **UART** connector: that is UART0 (GPIO43/44), already used by USB-UART.

Logic: **3.3 V TTL**. On the Waveshare HAT set the level jumper to **3.3V** (not 5 V).

## Powering the HAT

| HAT | Source |
|-----|--------|
| `5V` / HAT USB-C | 5 V supply with ≥ 2 A peaks, **separate** from the LCD 3V3 bus |
| `VBAT` | 3.7–4.2 V LiPo if the HAT supports it |
| Antenna | Module IPEX + LTE antenna with coverage |

Firmware **does not** pulse PWRKEY. Power the module as in the Waveshare wiki:

1. Insert a **nano-SIM** (data; PIN known or disabled).
2. Connect antenna and power.
3. Press **PWR** on the HAT (or hold PWRKEY ~1 s) if the PWR LED is off.
4. Wait 3–10 s: **PWR** solid, **NET** blinking when registered.

If AT does not answer (`modem 4G non risponde` / 4G modem not responding), firmware retries after about **3 minutes** and does not reboot the panel.

## Software

With no APN, 4G is **left alone** (UART1 stays free).

**Settings** on the LCD, `http://<IP>/`, or console:

```
pw> apn internet
pw> apn ibox.tim.it 1234
```

Example Italian APNs: `internet`, `ibox.tim.it`, `web.omnitel.it`, `iliad`, `mobile.vodafone.it`.

`net_supervisor` in `app_main.c`:

1. Try **2.4 GHz WiFi STA**.
2. If STA is up, 4G PPP is **disconnected**.
3. If STA is down and an APN is set, start PPP.
4. The **Powerwall-LCD** AP stays up for local setup even on 4G.

PPP DNS: `1.1.1.1` / `8.8.8.8`.

## Check

USB-UART serial, 115200:

```
I (...) app_lte: A7670E UART1 TX=15 RX=16 APN=internet
I (...) app_lte: PPP IP 10.x.x.x
```

On Live, the network kind should read **4G** (not WiFi) when STA is down.

Quick AT from a PC (HAT USB, not the LCD): `AT`, `AT+CPIN?`, `AT+CREG?`, `AT+COPS?`.
